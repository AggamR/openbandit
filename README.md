# OpenBandit
This is an open-source containerized implementation for the excelent overthewire's bandit exercises,
meant to deploy on airgapped environments for training, or just for fun.

## Basic Explenation
Each exercise has a different user and directory and so they're all set-up at build time,
using a bash script to set-up each excercise, under the `setups/` directory.
